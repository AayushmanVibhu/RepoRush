# RepoRush

A production-minded debugging practice interface built with Next.js, TypeScript, Monaco Editor, and Lucide.

## Live application

[Open RepoRush](https://aayushmanvibhu.github.io/RepoRush/)

The application currently ships as a static GitHub Pages deployment. User accounts,
durable progress, and server-side challenge execution are the next backend phase.

## Local development

```bash
npm install
npm run dev
```

The challenge catalog contains 29 JavaScript, Python, and Java debugging repositories.
Source edits and challenge workspaces persist in browser local storage.
