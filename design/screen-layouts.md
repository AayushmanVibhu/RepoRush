# Screen layouts

## Challenge explorer
Fixed 220px sidebar and a centered content region up to 1180px. Header, compact filters, and one structured list establish the hierarchy. Below 800px the sidebar becomes an icon rail and the table scrolls rather than clipping.

## Debugging workspace
50px persistent toolbar. Below it: 220px resizable explorer, flexible editor, and 318px resizable issue ticket. The editor owns remaining width. A 224px results panel occupies the editor bottom and can collapse. At narrow widths, the editor becomes the sole work surface.

## Submission result
Centered 680px column. Evaluation status leads, followed by three metrics, per-test results, practiced skills, and recovery/navigation actions.
